# Ward salience (M6 N2, DEC-092 note): No parameter change. The vote model's issue salience is computed per c

**Date:** 2026-11-20
**Area:** Ward salience (M6 N2, DEC-092 note)

## Parameter and change
No parameter change. The vote model's issue salience is computed per constituency (`concerns::salience_in`, by the town formula `salience_from`): each town's measured levels shifted by how much more or less the constituency's neighbourhoods feel each worry than the town (`political_levels`, within each concern's level range), towns weighted by residents; a whole town (mayoral race) reads the town's own salience bit for bit. A ward member's agenda reads the ward's levels (`npc::agenda_bonus_in`); town agendas and the crisis bonus are unchanged. Derived on demand (no save change)
