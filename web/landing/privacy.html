Privacy

Last updated 23 November 2026. This is a plain-language description of how the game works today. A lawyer has not reviewed it.

The short version

  • The game has no account, no sign-in, no advertising and no analytics.
  • The game does not send anything about you or your play to any server. It makes no requests except to load its own files from this site.
  • Your games are saved in your browser, on your device. They go nowhere unless you choose to export one or send a bug report.
  • The game sets no cookies.

What is stored on your device, and why

Everything below stays in your browser. The game needs it to work, and none of it is read by anyone but the game.

WhereWhatWhy
IndexedDB, database mandate Your saved runs (the game state, its seed and settings, and the town's name), story-mode checkpoints, and a random device identifier. So you can stop and carry on. The identifier is a random number made on your device, used to label saves. It is not linked to you.
IndexedDB, database mandate-town-plans Street layouts the game has already drawn (the newest few). So towns open faster.
Local storage A few display choices: the selected map layer, the pocket's tab and whether it is docked, the map scope. So the game looks the way you left it.
Cache storage and a service worker The game's own files (code, engine, images). So the game loads fast and works offline.

The landing page reads the list of your saved runs on this device to show a “continue” link. It does not send it anywhere.

What the host may log

This site is served by GitHub Pages. Like any web host, GitHub receives your IP address and browser details when your browser asks for a page or a file, and it may log them. Mandate does not control that and does not receive those logs. See GitHub’s privacy statement. The game loads nothing from any other site: no fonts, scripts, analytics or advertising services.

Bug reports

“Report a problem” in the game makes a file on your device. It holds the game’s seed and settings and every move you made in that game, the game as saved, the last few error messages, your screen size, your browser’s name and version, and whatever you type in the description box. You can see what it will contain before you save it. Nothing is uploaded. You choose whether to send the file, and to whom. Do not type anything into the description that you would not want the developers to read.

Exported runs

“Export” makes a .mandate file of a saved run. It stays where you put it. Anyone you give it to can open the run.

Deleting everything

  • One run: on the game’s title screen, press Delete beside it. This removes that run from this browser.
  • Everything: clear this site’s data in your browser (usually Settings, Privacy, Site data, find this site, Delete; the game’s saved runs, layouts, settings and offline files are all removed). Uninstalling the app from your home screen does the same on most phones. Exported files and bug-report files are separate; delete them yourself.

The game has no “delete all saves” button yet. Clearing site data is the way to remove everything at once.

If this changes

An optional account to sync saves between devices may be added later. If it is, this page will be rewritten before it goes live, and the sync will be opt-in: the game will keep working without it.

Contact

Questions, or a request about your data: open an issue at github.com/jackhale98/mandate/issues. Because nothing is collected, there is no data about you for the developers to look up or delete.

Mandate is a work of fiction. The people, parties, towns and events in every game are made up by the game, and any likeness to real ones is chance.
